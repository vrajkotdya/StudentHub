About the StudentHub Initiative

The StudentHub platform was created as a progressive, semester-long project under the course Web Development Frameworks (ITUE203) for 3rd Semester B.Tech students in the Faculty of Technology and Engineering (FTE) at CHARUSAT.

The vision of StudentHub is to establish a seamless, digital-first campus environment where students can self-manage academic milestones, register for university initiatives, and engage with departmental governance in an accessible, transparent manner.

Vision & Educational Objectives

Our Vision

To emerge as a state-of-the-art academic management prototype adhering strictly to global W3C web accessibility guidelines, mobile-first responsiveness, and robust backend engineering principles.

Program Learning Outcomes (CO / PO Alignment)

  • CO1: Formulate web page structure and accessible data forms using semantic HTML5 tags and web standards.
  • CO2: Design responsive, multi-screen fluid user interfaces utilizing CSS Grid, Flexbox, and modern CSS3 properties.
  • CO3: Implement client-side logic, event-driven interactivity, and form validations using modern ECMAScript.
  • CO4: Integrate asynchronous REST APIs and asynchronous JSON data pipelines without page reloads.
  • CO5: Build secure server-side applications with authentication, sessions, role-based controls, and database transactions.
